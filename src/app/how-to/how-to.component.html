Setup Guide

Get your Fine-grained Personal Access Token (recommended) in 3 simple steps.

  1. Navigate to Fine-Grained Tokens Settings

    Go to the GitHub Fine-Grained Personal Access Tokens Settings page. Click on the Generate new token button in the top right corner.

  2. Select Administration Permissions

    Give your token a descriptive name (e.g., repo-scrubber). Under Repository access, select the repositories you want to manage (or select All repositories). Scroll down to Repository permissions, find the Administration permission, and set it to Read and write.

    Administration Access: Read and Write (required to delete repositories)
    Security Warning: Only grant the Administration (Read and Write) repository permission. Do not grant any other unnecessary repository or organization permissions to protect your account.

  3. Copy Token & Start Scrubbing

    Click Generate token at the bottom of the page. Copy the generated token immediately (it starts with github_pat_) — you won't be able to see it again. Paste the token along with your GitHub username on the Scrub page.

Legacy Method: Classic Tokens (Not Recommended)
Legacy

Classic Personal Access Tokens grant wider account-level scopes. While supported, they are less secure than fine-grained tokens.

  1. Navigate to GitHub Token Settings

    Go to GitHub Personal Access Tokens Settings . Click on the Generate new token dropdown and select Generate new token (classic).

  2. Select Required Scopes

    Give your token a descriptive note (e.g., repo-scrubber). To allow bulk deletion, check the following checkboxes under scopes:

    repo Full control of public & private repositories
    delete_repo Delete repositories
    Security Warning: Only grant these two classic scopes. Do not grant unnecessary scopes to protect your account.

  3. Copy Token & Start Scrubbing

    Click Generate token at the bottom of the page. Copy the generated token string immediately — you won't be able to see it again. Paste the token along with your GitHub username on the Scrub page.
