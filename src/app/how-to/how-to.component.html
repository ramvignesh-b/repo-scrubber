Setup Guide Get your Personal Access Token in 3 simple steps

Go to GitHub Personal Access Tokens Settings. Click on the Generate new token dropdown and select Generate new token (classic).

Give your token a descriptive note (e.g., repo-scrubber). To allow bulk deletion, check the following checkboxes under scopes:

  • check_circle repo (Full control of public & private repositories)
  • check_circle delete_repo (Delete repositories)
warning Security Warning: Only grant these two classic scopes. Do not grant unnecessary scopes to protect your account.

Click Generate token at the bottom of the page. Copy the generated token string immediately. Paste the copied token along with your GitHub username on the Scrub page.
