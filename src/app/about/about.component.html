About Repo Scrubber
Simplify your GitHub workspace cleanup.

What is this tool?

Repo Scrubber is a focused web application designed to help you bulk-delete unwanted or obsolete GitHub repositories. If you frequently fork repositories or accumulate old experimental projects, this utility cuts down on the tedious manual deletion process.

Angular 22 Primer Design System Cloudflare Pages

Why was it built?

Manually deleting a repository on GitHub requires navigating multiple settings pages and typing the full repository name to confirm. For developers looking to tidy up their workspace, this flow is slow and repetitive.

While CLI scripts can automate this task, a secure web interface offers a more intuitive and visually reassuring experience. Repo Scrubber provides a simple, click-to-delete interface to manage multiple repositories efficiently.

Security & Privacy

Your personal access token is never saved, logged, or transmitted to any third-party server. All API calls are executed directly from your browser to GitHub's public API endpoints.

Furthermore, this tool operates on both public and private repositories owned by your GitHub account. Always double-check before deleting as this action is irreversible.
